Convertidor de Markdown a HTML

Markdown es la forma más rápida de escribir texto con formato: encabezados, listas, negritas, enlaces y tablas usando solo símbolos simples. Este convertidor transforma tu Markdown en HTML limpio mientras escribes. Incluye una vista previa para ver el resultado y el código listo para copiar en tu blog, tu CMS, un correo o una página web. Soporta la sintaxis de GitHub con tablas, tachado y bloques de código.

Cómo usar

  1. 1

    Escribe o pega tu texto en Markdown en el panel izquierdo

  2. 2

    Mira la vista previa formateada o cambia a la pestaña «Código HTML»

  3. 3

    Activa las opciones que necesites: sintaxis de GitHub y saltos de línea como <br>

  4. 4

    Pulsa «Copiar HTML» para llevar el código a tu sitio

Beneficios

  • Conversión instantánea mientras escribes
  • Vista previa aislada y segura
  • Soporte de tablas, tachado y listas de GitHub
  • Opción de convertir saltos de línea simples en <br>
  • Usa marked, un motor de Markdown ampliamente probado

Sintaxis básica de Markdown

Los encabezados se escriben con almohadillas: # para el título principal, ## para una sección. Las negritas van entre dobles asteriscos (**texto**) y las cursivas entre asteriscos simples (*texto*). Las listas empiezan con un guion o un número seguido de punto. Los enlaces se escriben como [texto](https://direccion.com) y las imágenes igual pero con un signo de exclamación delante. Las citas empiezan con > y el código en línea va entre acentos graves.

Markdown al estilo GitHub

GitHub Flavored Markdown (GFM) añade elementos muy útiles: tablas con columnas separadas por barras verticales, texto tachado con dobles virgulillas (~~texto~~), listas de tareas con [ ] y [x] y detección automática de enlaces. Con la opción activada, el convertidor los reconoce. Es el dialecto que usan GitHub, muchos editores de notas y buena parte de la documentación técnica.

Saltos de línea y párrafos

En Markdown estándar, un salto de línea simple no crea un salto en el HTML: las líneas seguidas se unen en un solo párrafo. Para empezar un párrafo nuevo, deja una línea en blanco. Si prefieres que cada salto de línea se respete, como en un mensaje de chat, activa la opción «Un salto de línea = <br>». Es útil para poemas, direcciones o letras de canciones.

Seguridad de la vista previa

Markdown permite incluir HTML directamente, lo que podría incluir scripts. Por eso la vista previa se muestra dentro de un marco aislado que no ejecuta código y no puede afectar la página. Si vas a publicar el HTML generado a partir de texto de terceros, como comentarios de usuarios, pásalo por un sanitizador en tu servidor antes de mostrarlo.
