Convertidor de Markdown a HTML

Actualizado el 25 de octubre de 2026 · Ver fuentes

Escribe o pega Markdown y obtén el HTML al instante, con vista previa. Admite el Markdown de GitHub (tablas, listas de tareas y tachado) y la opción de convertir cada salto de línea en un salto real.

Ejemplo resuelto

¿Cómo se escribe una lista de tareas en Markdown?

Requisito
Activar «Markdown de GitHub»
  1. 1

    Empieza cada línea con guion y corchetes.

    - [ ] Comprar aguacates

  2. 2

    Marca con una x las tareas hechas.

    - [x] Picar cebolla

  3. 3

    El HTML resultante incluye casillas de verificación.

    <li><input checked="" disabled="" type="checkbox"> Picar cebolla</li>
