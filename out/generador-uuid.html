¿Es seguro usar un UUID como contraseña o token?
Un UUID v4 tiene 122 bits aleatorios, suficiente para que no se adivine. Pero no es una contraseña: para eso usa el generador de contraseñas. Si necesitas verificar que un archivo no cambió, usa un hash.
