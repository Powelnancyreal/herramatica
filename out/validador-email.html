Validador de Email

Actualizado el 25 de octubre de 2026

Comprueba si una dirección de correo tiene un formato correcto, si el dominio puede recibir correo (registros MX) y si tiene errores típicos como «gmial.com». Funciona con una dirección o con una lista de hasta 200.

Comprobamos la sintaxis y si el dominio tiene servidores de correo (registro MX, consultado a Cloudflare DNS). Ninguna herramienta web puede confirmar que un buzón concreto exista sin enviarle un mensaje.

¿Qué direcciones de correo son válidas y cuáles no?

Dirección¿Válida?Por qué
ana.lopez@empresa.comSíFormato estándar
ana+boletin@gmail.comSíEl + crea un alias que llega al mismo buzón
ana lopez@empresa.comNoLos espacios no están permitidos
ana@@empresa.comNoSolo puede haber una @
ana@empresaNoFalta la extensión del dominio
ana@gmial.comFormato sí, pero sospechosaProbable error al escribir gmail.com

¿Cómo mantener limpia una lista de correos?

  • ✓Valida las direcciones al recogerlas, no meses después.
  • ✓Usa doble confirmación: un correo con enlace para verificar la suscripción.
  • ✓Elimina los correos que rebotan de forma permanente.
  • ✓Evita direcciones de correos desechables en formularios importantes.
  • ✓Revisa la lista cada pocos meses y quita a quien no abre nada.

¿Qué otras herramientas ayudan con el correo electrónico?

Para una firma profesional, el generador de firma de email; para medir tus campañas, añade parámetros con el generador de UTM. Si necesitas buscar correos dentro de un texto largo, el probador de regex te ayuda.
