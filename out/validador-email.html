Validador de Email

Comprobamos la sintaxis y si el dominio tiene servidores de correo (registro MX, consultado a Cloudflare DNS). Ninguna herramienta web puede confirmar que un buzón concreto exista sin enviarle un mensaje.

Un correo mal escrito significa un cliente que nunca recibe su confirmación o una campaña que rebota. Este validador de email revisa que la dirección tenga un formato correcto, detecta los errores de escritura más comunes en dominios populares (como gmial.com, hotmial.com o gmail.con) y te sugiere la corrección, avisa si el dominio es de correo temporal y consulta el DNS para comprobar si el dominio realmente puede recibir correo. Puedes validar un solo correo o una lista de hasta 200 a la vez.

  2. 2

  3. 3

Beneficios

  • Revisa la sintaxis con reglas del estándar de correo
  • Sugiere correcciones para errores típicos de escritura
  • Comprueba si el dominio tiene servidores de correo (registro MX)
  • Detecta dominios de correo temporal o desechable
  • Validación en lote de hasta 200 correos
  • Gratis y sin registro

Qué comprueba este validador

Primero revisa la sintaxis: que haya una sola @, que la parte del usuario tenga como máximo 64 caracteres y solo caracteres permitidos, sin puntos al inicio, al final o seguidos, y que el dominio tenga una extensión válida. Después compara el dominio con los proveedores más populares para detectar errores de una o dos letras. Por último, consulta el DNS público de Cloudflare para saber si el dominio tiene registros MX, que son los servidores encargados de recibir el correo.

¿Qué es un registro MX?

Los registros MX (mail exchanger) indican a qué servidores se debe entregar el correo de un dominio. Si un dominio no tiene registros MX, lo más probable es que no pueda recibir correos, aunque tenga una página web. Si el dominio ni siquiera existe, cualquier correo enviado a él rebotará. Esta comprobación elimina muchos errores, como dominios inventados o empresas que ya cerraron su correo.

Lo que ningún validador web puede comprobar

Una dirección puede tener un formato perfecto y un dominio que recibe correo, y aun así no existir: por ejemplo, un buzón con una letra de más en un dominio válido. Para confirmar que un buzón concreto existe habría que conectarse al servidor de correo, algo que los navegadores no permiten y que muchos servidores bloquean para evitar el spam. La única prueba definitiva es enviar un correo de confirmación con un enlace, el conocido doble opt-in.

Por qué validar correos mejora tus envíos

Enviar correos a direcciones inexistentes aumenta tu tasa de rebote, y los proveedores como Gmail y Outlook la usan para decidir si tus mensajes van a la bandeja de entrada o a spam. Limpiar tu lista antes de una campaña, corregir errores de escritura en los formularios de registro y evitar los dominios desechables te ayuda a proteger la reputación de tu dominio y a llegar a más clientes reales.

Preguntas frecuentes

No con total seguridad. Podemos comprobar el formato y que el dominio reciba correo, pero no si el buzón concreto existe. La única forma segura es enviarle un correo de confirmación.
