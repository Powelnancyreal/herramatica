Convertidor de Imagen a Base64

Incrustar una imagen como texto Base64 permite usarla directamente en HTML, CSS, JSON o correos sin un archivo aparte. Con este convertidor arrastras una imagen y obtienes al instante su data URI completo, el Base64 puro y fragmentos listos para una etiqueta img, un background en CSS o Markdown. También funciona al revés: pega un texto Base64 y verás la imagen para descargarla. La conversión se hace en tu navegador y la imagen no se sube a ningún servidor.

Cómo usar

  1. 1

    Elige «Imagen → Base64» y arrastra una imagen o selecciónala desde tu equipo

  2. 2

    Revisa la vista previa, el tamaño original y el tamaño en Base64

  3. 3

    Copia el formato que necesites: data URI, Base64, HTML, CSS o Markdown

  4. 4

    Para decodificar, elige «Base64 → Imagen», pega el texto y descarga la imagen

Beneficios

  • Acepta PNG, JPG, GIF, WebP, SVG e ICO
  • Cinco formatos de salida listos para copiar
  • Muestra cuánto aumenta el tamaño en Base64
  • Decodifica Base64 a imagen con detección del formato
  • Arrastrar y soltar
  • Privado: la imagen no sale de tu equipo

Qué es un data URI

Un data URI incrusta el contenido de un archivo dentro de una URL. Tiene la forma data:[tipo];base64,[datos], por ejemplo data:image/png;base64,iVBORw0KGgo… El navegador lo interpreta como si fuera un archivo, así que puedes ponerlo en el atributo src de una imagen, en url() de CSS o en un documento Markdown. Base64 transforma los bytes de la imagen en texto usando 64 caracteres seguros: letras, números, + y /.

Cuándo conviene usar Base64

Es útil para imágenes pequeñas, como iconos, logotipos o fondos de pocos kilobytes, porque evita una petición HTTP adicional. También para incluir imágenes en correos HTML, en archivos JSON de una API, en HTML de un solo archivo o en pruebas automatizadas. Para imágenes grandes no conviene: el texto Base64 ocupa alrededor de un 33% más que el archivo original, no se almacena en caché por separado y hace más pesado el HTML o el CSS que lo contiene.

Por qué Base64 ocupa más

Base64 representa cada 3 bytes de datos con 4 caracteres de texto, así que el tamaño crece en una proporción de 4/3, más el relleno final. Una imagen de 30 KB se convierte en unos 40 KB de texto. Si el servidor comprime el HTML con gzip o brotli, parte de ese aumento se compensa, pero las imágenes ya comprimidas, como JPG o WebP, casi no se reducen más. La herramienta muestra el aumento exacto para que decidas.

Decodificar Base64 a imagen

Si encuentras un texto Base64 en un JSON, una base de datos o el código de una página, pégalo en el modo «Base64 → Imagen». La herramienta acepta el data URI completo o solo los datos y reconoce el formato por la firma de sus primeros caracteres: /9j/ para JPEG, iVBOR para PNG, R0lGOD para GIF y UklGR para WebP. Después puedes ver la imagen y descargarla.

Preguntas frecuentes

No. La conversión usa la API FileReader de tu navegador y la imagen nunca sale de tu equipo.
