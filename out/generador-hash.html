Generador de Hash MD5, SHA-1 y SHA-256

Actualizado el 25 de octubre de 2026

Calcula el hash MD5, SHA-1, SHA-256, SHA-384 y SHA-512 de un texto o de un archivo, a la vez y en tu navegador. Sirve para verificar descargas, comparar archivos y detectar cambios.

¿Cómo comprobar que un archivo descargado no está alterado?

  1. 1

    Copia el hash oficial

    La web de descarga suele publicar un SHA-256 junto al archivo.

  2. 2

    Carga el archivo aquí

    Se procesa en tu navegador, sin subirse a ningún servidor.

  3. 3

    Compara los dos hashes

    Si coinciden letra a letra, el archivo es idéntico al publicado. Si no, descárgalo de nuevo.

¿Qué diferencia hay entre hash, cifrado y codificación?

Hash

  • Un solo sentido: no se puede revertir.
  • Siempre la misma longitud.
  • Para verificar integridad.

Cifrado

  • Se revierte con una clave.
  • Protege la confidencialidad.
  • Ejemplo: AES, el candado de HTTPS.

Codificación

  • Se revierte sin clave.
  • Solo cambia el formato.
  • Ejemplo: Base64.

¿Por qué no se deben guardar contraseñas con SHA-256?

Porque es demasiado rápido: un atacante puede probar miles de millones de contraseñas por segundo. Para contraseñas se usan algoritmos lentos y con sal, como bcrypt, scrypt o Argon2. Para crear contraseñas robustas usa el generador de contraseñas; para identificadores únicos, el generador de UUID.
