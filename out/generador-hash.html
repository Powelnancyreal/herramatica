Generador de Hash MD5, SHA-1 y SHA-256

Un hash es la huella digital de un texto o un archivo: cualquier cambio, por mínimo que sea, produce un hash completamente distinto. Este generador calcula a la vez los hash MD5, SHA-1, SHA-256, SHA-384 y SHA-512 de un texto o de un archivo de hasta 200 MB, y te permite pegar el hash que publica un sitio de descarga para comprobar al instante si tu archivo es idéntico al original. Todo el cálculo se hace en tu navegador, por lo que tus archivos nunca se suben a internet.

Cómo usar

  1. 1

    Elige si vas a calcular el hash de un texto o de un archivo

  2. 2

    Escribe el texto o selecciona el archivo: los cinco hash se calculan automáticamente

  3. 3

    Copia el hash del algoritmo que necesites, en minúsculas o mayúsculas

  4. 4

    Para verificar una descarga, pega el hash publicado y comprueba si coincide

¿Qué es una función hash?

Una función hash criptográfica transforma cualquier cantidad de datos en una cadena de longitud fija. Tiene tres propiedades clave: el mismo contenido siempre produce el mismo hash; un cambio mínimo, incluso de un solo bit, produce un hash totalmente diferente; y no es posible reconstruir el contenido original a partir del hash. Por eso se usa para verificar la integridad de archivos, detectar duplicados, firmar documentos digitalmente y almacenar contraseñas de forma segura.

MD5, SHA-1 y SHA-256: cuál usar

MD5 (128 bits) y SHA-1 (160 bits) se consideran rotos para usos de seguridad: se han demostrado colisiones, es decir, dos contenidos distintos con el mismo hash; en el caso de SHA-1, públicamente en 2017. Siguen siendo útiles para detectar errores accidentales o verificar descargas antiguas. Para cualquier uso actual, lo recomendado es la familia SHA-2: SHA-256 es el estándar más extendido, usado en certificados TLS, Git y Bitcoin, mientras que SHA-384 y SHA-512 ofrecen salidas más largas.

Cómo verificar la integridad de una descarga

Muchos proyectos de software publican el hash SHA-256 de sus archivos junto al enlace de descarga. Para comprobar que tu archivo no se dañó ni fue modificado, selecciónalo en la pestaña «Archivo», pega el hash publicado en el campo de verificación y la herramienta te dirá si coincide y con qué algoritmo. Si no coincide, vuelve a descargar el archivo desde la fuente oficial y no lo ejecutes.

Hashes y contraseñas

Nunca guardes contraseñas con un hash simple como MD5 o SHA-256: al ser funciones rápidas, un atacante puede probar miles de millones de combinaciones por segundo. Para contraseñas se usan algoritmos lentos y con sal diseñados para ello, como Argon2, bcrypt o scrypt. Esta herramienta sirve para verificar integridad y para aprender, no para proteger contraseñas en producción.

Preguntas frecuentes

No se puede «descifrar» porque un hash no es un cifrado. Sin embargo, los hash de contraseñas comunes pueden encontrarse en tablas precalculadas, por lo que MD5 no es seguro para guardar contraseñas.
