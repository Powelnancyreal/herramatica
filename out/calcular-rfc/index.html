Calculadora de RFC y RFC Genérico

Si no tienes, se usará X automáticamente.

¿Buscas el RFC genérico para facturar a público en general, o necesitas calcular tu propio RFC personal? Esta página resuelve ambas cosas: te explicamos los códigos de RFC genérico que usa el SAT (XAXX010101000 y XEXX010101000) y cuándo corresponde cada uno, y además incluye una calculadora gratuita que genera la clave base de tu RFC personal a partir de tu nombre, apellidos y fecha de nacimiento, siguiendo las reglas públicas del SAT. No necesitas CURP ni registro.

Cómo usar

  1. 1

    Escribe tu nombre o nombres en el primer campo (por ejemplo: Juan Carlos)

  2. 2

    Ingresa tu apellido paterno con o sin acento — la herramienta lo normaliza automáticamente

  3. 3

    Añade tu apellido materno si lo tienes; si no, el sistema usa X como indica el SAT

  4. 4

    Selecciona tu fecha de nacimiento y pulsa Calcular RFC para obtener el resultado

¿Qué es el RFC en México?

El RFC (Registro Federal de Contribuyentes) es la clave fiscal que el SAT asigna a personas físicas y morales en México para identificarlas ante el fisco. Se utiliza para emitir facturas electrónicas (CFDI), presentar declaraciones de impuestos y realizar cualquier trámite tributario. Para personas físicas, el RFC se compone de cuatro letras derivadas del nombre y apellidos, seis dígitos de la fecha de nacimiento en formato YYMMDD, y tres caracteres adicionales llamados homoclave que solo el SAT puede calcular y asignar.

¿Qué es el RFC genérico y cuál es el código correcto?

El RFC genérico es un valor fijo y oficial que el SAT autoriza usar cuando el cliente de una venta no proporciona su RFC o no lo necesita para efectos fiscales, típicamente en ventas al público en general o en facturas globales. Existen dos códigos: XAXX010101000, para operaciones con clientes nacionales (mexicanos), y XEXX010101000, para operaciones con clientes extranjeros. En ambos casos, el nombre o razón social que se registra en el CFDI es "PÚBLICO EN GENERAL". A diferencia de un RFC personal, el RFC genérico no se tramita ni se calcula: es el mismo valor predefinido para todos los negocios que facturan en México, y no permite identificar al comprador ante el SAT ni sirve para que este deduzca impuestos con esa factura.

Ejemplo de RFC calculado paso a paso

Tomemos a Juan Carlos López García, nacido el 21 de agosto de 1995. El algoritmo toma la primera letra del apellido paterno (L), la primera vocal interna del apellido paterno (O de López), la primera letra del apellido materno (G de García) y la primera letra del nombre (J de Juan). A estos cuatro caracteres se añade la fecha en formato YYMMDD: 950821. El RFC base resultante es LOGJ950821. A este resultado el SAT añade la homoclave oficial para completar el RFC.

¿Se puede obtener el RFC oficial aquí?

No. Esta herramienta calcula la clave base del RFC siguiendo las reglas públicas del SAT, pero el RFC oficial incluye una homoclave de tres caracteres que solo el SAT puede asignar. Para obtener tu RFC completo y oficial debes tramitarlo en el portal sat.gob.mx o en una oficina del SAT. Esta calculadora es útil para conocer tu clave base, entender cómo se construye tu RFC o verificar que lo recuerdas correctamente antes de acudir al SAT.

Preguntas frecuentes

El RFC base se calcula tomando cuatro letras: la primera letra del apellido paterno, la primera vocal interna del apellido paterno, la primera letra del apellido materno y la primera letra del nombre. A continuación se añade la fecha de nacimiento en formato YYMMDD. Por ejemplo, Ana Pérez Ríos nacida el 05/03/1988 daría PERA880305.
