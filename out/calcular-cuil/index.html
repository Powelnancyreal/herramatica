Calcular CUIL (Argentina)

El CUIL (Código Único de Identificación Laboral) se obtiene a partir de tu número de DNI, un prefijo de dos dígitos (según sexo registrado) y un dígito verificador calculado matemáticamente. Esta calculadora reproduce el algoritmo oficial de AFIP para obtener tu CUIL completo a partir de tu DNI, y también permite validar si un CUIL o CUIT completo ya existente es correcto.

Cómo usar

  1. 1

    Introduce tu número de DNI, sin puntos

  2. 2

    Selecciona el sexo registrado o "persona jurídica" si corresponde

  3. 3

    Pulsa "Calcular CUIL" para obtener tu código completo con el formato XX-XXXXXXXX-X

  4. 4

    Usa la pestaña "Validar CUIL/CUIT" para comprobar si un código que ya tienes es correcto

Beneficios

  • Aplica el algoritmo oficial del módulo 11 de AFIP con los pesos exactos [5,4,3,2,7,6,5,4,3,2]
  • Maneja automáticamente el caso especial en que el dígito verificador da 10, reintentando con el prefijo 23
  • Incluye un modo de validación para CUIL y CUIT completos
  • Rellena automáticamente con ceros los DNI de 7 dígitos
  • Gratis, sin registro y calculado directamente en tu navegador

¿Cómo se calcula el CUIL a partir del DNI?

Se antepone al DNI un prefijo de dos dígitos (20 para hombres, 27 para mujeres, o 30 para personas jurídicas), formando una secuencia de 10 dígitos. Cada uno de esos 10 dígitos se multiplica por su peso correspondiente en la serie [5,4,3,2,7,6,5,4,3,2], se suman los resultados, se calcula el resto de dividir esa suma entre 11, y el dígito verificador es 11 menos ese resto. Si el resultado es 11, el dígito verificador es 0; si es 10, no es válido con ese prefijo y se debe usar el prefijo 23 en su lugar.

¿Qué diferencia hay entre CUIL y CUIT?

El CUIL identifica a una persona como trabajador en relación de dependencia, mientras que el CUIT (Código Único de Identificación Tributaria) identifica a una persona o empresa ante la AFIP a efectos impositivos, típicamente cuando se factura de forma independiente o se es titular de una empresa. Ambos comparten exactamente el mismo algoritmo de cálculo del dígito verificador y el mismo formato de 11 dígitos; la diferencia está en el prefijo utilizado y el contexto en el que se usa cada uno.

Preguntas frecuentes

El algoritmo del CUIL siempre trabaja con una base de 8 dígitos para el número de documento, por lo que los DNI más antiguos de 7 dígitos se completan con un cero a la izquierda (por ejemplo, 1234567 se convierte en 01234567) antes de aplicar la fórmula.
