¿Cómo se calcula el determinante de una matriz?

Para una matriz 2×2, el determinante se calcula como (a×d) − (b×c). Para una matriz 3×3, se usa la expansión por cofactores a lo largo de la primera fila, combinando los determinantes de las submatrices 2×2 resultantes de eliminar cada fila y columna correspondiente. El determinante indica, entre otras cosas, si una matriz tiene inversa: si es igual a cero, la matriz no es invertible.

¿Cómo se calcula la matriz inversa?

Esta calculadora usa el método de Gauss-Jordan: se coloca la matriz original junto a la matriz identidad, y mediante operaciones de fila (multiplicar, sumar o intercambiar filas) se transforma la matriz original en la identidad; al hacerlo, la matriz identidad original se transforma en la matriz inversa. Este método funciona para cualquier matriz cuadrada cuyo determinante no sea cero.

Preguntas frecuentes

Una matriz cuadrada no tiene inversa cuando su determinante es igual a cero; en ese caso, se dice que la matriz es "singular" y esta calculadora te lo indicará en lugar de mostrar un resultado incorrecto.
