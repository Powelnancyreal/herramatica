¿Para qué se usa Base64 en la práctica?

Adjuntos de correo

Los correos solo transportan texto: los archivos adjuntos viajan codificados en Base64.

Email

Imágenes en HTML o CSS

Una imagen pequeña puede ir dentro del código como data URI, sin pedir un archivo aparte.

data:image

Tokens y APIs

Los JWT y la autenticación básica HTTP codifican sus datos en Base64.

Auth

¿Qué diferencia hay entre Base64 normal y Base64 para URL?

Base64 estándar

  • Usa los caracteres + y /.
  • Termina con = de relleno.
  • Para correos, archivos y datos en general.

Base64 URL

  • Cambia + por - y / por _.
  • Normalmente sin =.
  • Para URL, nombres de archivo y tokens JWT.

Base64 no protege nada: cualquiera puede decodificarlo en un segundo. Nunca lo uses para «ocultar» contraseñas o datos personales.

¿Cómo convertir una imagen a Base64?

Usa imagen a Base64, que genera el data URI listo para pegar. Para comprobar la integridad de un archivo, en cambio, necesitas un hash: el generador de hash.
