Codificador y Decodificador Base64

Base64 es la forma estándar de representar datos binarios, como imágenes o archivos, usando solo caracteres de texto. Este codificador convierte cualquier texto a Base64 y lo decodifica de vuelta, con soporte completo de UTF-8, así que las tildes, la ñ y los emojis funcionan correctamente, algo que falla en muchas herramientas. También genera Base64 seguro para URL y convierte archivos e imágenes en data URI listos para incrustar en HTML o CSS. Todo ocurre en tu navegador: ni tus textos ni tus archivos se suben a ningún servidor.

Cómo usar

  1. 1

    Elige «Codificar texto», «Decodificar» o «Archivo a Base64»

  2. 2

    Escribe o pega el texto; el resultado aparece al instante

  3. 3

    Para URLs o tokens, activa la opción de Base64 seguro para URL

  4. 4

    Para archivos, selecciona el archivo y copia el data URI generado

Beneficios

  • Soporte completo de UTF-8: acentos, ñ y emojis
  • Base64 estándar y variante segura para URL
  • Convierte imágenes y archivos a data URI con vista previa
  • Detecta caracteres inválidos al decodificar
  • Resultado instantáneo y botón de copiar
  • Privado: nada se sube a internet

¿Qué es Base64 y para qué sirve?

Base64 es un sistema de codificación definido en el RFC 4648 que representa cualquier dato binario usando 64 caracteres seguros: las letras A-Z y a-z, los dígitos 0-9 y los símbolos + y /, con = como relleno. Se usa para enviar archivos adjuntos por correo, incrustar imágenes pequeñas en HTML o CSS, transportar datos binarios en JSON o XML, y en los tokens de autenticación como JWT o la cabecera Basic Auth. Base64 no es un método de cifrado: cualquiera puede decodificarlo.

Cómo funciona la codificación

Base64 toma los datos de 3 en 3 bytes (24 bits) y los divide en 4 grupos de 6 bits; cada grupo se convierte en uno de los 64 caracteres. Por eso el resultado ocupa aproximadamente un 33% más que el original. Si los datos no son múltiplo de 3 bytes, se añaden uno o dos signos = al final. Por ejemplo, el texto «Hola» se codifica como SG9sYQ==. Antes de codificar, el texto se convierte a bytes con UTF-8, que es lo que permite representar correctamente los caracteres del español.

Base64 seguro para URL

Los caracteres + y / tienen un significado especial en las URL y en los nombres de archivo. La variante Base64url, también definida en el RFC 4648, los sustituye por - y _ y suele omitir el relleno =. Es la que se usa en los tokens JWT y en parámetros de URL. Este decodificador acepta ambas variantes automáticamente, así que puedes pegar un fragmento de un JWT y ver su contenido.

Imágenes en Base64: data URI

Un data URI incrusta un archivo directamente en el código con el formato data:tipo/mime;base64,datos. Es útil para iconos pequeños, imágenes en correos HTML o para evitar una petición extra al servidor. Sin embargo, para imágenes grandes no conviene, porque aumenta el tamaño un 33% y el navegador no puede guardarlas en caché por separado. Esta herramienta genera el data URI de cualquier archivo de hasta 10 MB y muestra una vista previa si es una imagen.
