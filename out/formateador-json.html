Actualizado el 25 de octubre de 2026

Pega un JSON y obtén al instante una versión legible con sangría, una versión minificada o el error exacto, con línea y columna, si no es válido. Todo se procesa en tu navegador.

¿Cuándo formatear y cuándo minificar un JSON?

Formatear

  • Para leerlo, revisarlo o depurar una respuesta de API.
  • Para guardarlo en un repositorio y ver cambios línea a línea.
  • Para documentación.

Minificar

  • Para enviarlo por la red o guardarlo en una base de datos.
  • Ocupa menos al quitar espacios y saltos de línea.
  • Para incrustarlo en una URL o en un atributo HTML.

¿Qué otras herramientas sirven para trabajar con JSON?

Para pasar una hoja de cálculo a JSON, usa el conversor de CSV a JSON; para leer el contenido de un token, el decodificador JWT; y para buscar patrones en el texto, el probador de regex.
