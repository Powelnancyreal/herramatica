Formateador y Validador JSON

Tu JSON se procesa en tu navegador y nunca se envía a ningún servidor.

Este formateador JSON convierte un JSON comprimido o desordenado en un texto legible con sangría, lo minifica para ocupar menos espacio y, sobre todo, lo valida. Cuando el JSON tiene un error, no te muestra un mensaje críptico: te indica la línea y la columna exactas, señala el carácter con una flecha y explica el problema en español, como una coma sobrante, una clave sin comillas dobles o una cadena sin cerrar. Todo se procesa en tu navegador, así que puedes usarlo con datos sensibles, respuestas de APIs o archivos de configuración sin enviarlos a ningún servidor.

Cómo usar

  1. 1

    Pega tu JSON en el cuadro de entrada, o pulsa «Cargar ejemplo» para probar

  2. 2

    Elige la sangría (2 espacios, 4 espacios o tabulador) y si quieres ordenar las claves alfabéticamente

  3. 3

    Pulsa «Formatear y validar» para embellecerlo, o «Minificar» para compactarlo en una línea

  4. 4

    Si hay un error, corrígelo en la línea y columna indicadas; si es válido, cópialo con un clic

Beneficios

  • Localiza los errores con línea, columna y una flecha sobre el carácter
  • Explica cada error en español y cómo corregirlo
  • Embellece con 2, 4 espacios o tabuladores, o minifica
  • Ordena las claves de los objetos alfabéticamente
  • Muestra el tamaño del resultado en bytes
  • 100% privado: el JSON no sale de tu navegador

¿Qué es JSON?

JSON (JavaScript Object Notation) es el formato de texto más usado para intercambiar datos entre aplicaciones, APIs web y archivos de configuración. Se compone de objetos entre llaves con pares «clave»: valor, arreglos entre corchetes, textos entre comillas dobles, números, true, false y null. Aunque proviene de JavaScript, lo leen y escriben prácticamente todos los lenguajes de programación. Su especificación está definida en el estándar ECMA-404 y en el RFC 8259.

Los errores de JSON más comunes

La mayoría de los errores se deben a costumbres de JavaScript que JSON no permite. Las comas finales, como en {"a": 1,}, no son válidas. Las claves y los textos deben ir siempre entre comillas dobles; las comillas simples no se aceptan. Tampoco se permiten comentarios, valores como undefined o NaN, ni números con ceros a la izquierda como 007. Los saltos de línea dentro de un texto deben escribirse como \n. El validador detecta todos estos casos y te dice exactamente dónde están.

Formatear o minificar: cuándo usar cada uno

El JSON formateado, con sangría y saltos de línea, es ideal para leerlo, depurar una respuesta de una API, revisar un archivo de configuración o compartirlo en documentación. El JSON minificado elimina todos los espacios innecesarios y ocupa menos bytes, lo que conviene para enviarlo por la red o guardarlo en una base de datos. Ambos representan exactamente los mismos datos. Ordenar las claves alfabéticamente ayuda a comparar dos JSON o a revisar cambios en un control de versiones.

Privacidad: tu JSON no sale de tu navegador

Muchos formateadores online envían tu texto a un servidor para procesarlo, lo cual es un riesgo cuando pegas respuestas de APIs con tokens, datos de clientes o configuraciones internas. Esta herramienta funciona completamente en tu navegador con JavaScript: puedes desconectarte de internet después de cargar la página y seguirá funcionando. No guardamos ni registramos nada de lo que pegas.

Preguntas frecuentes

Pégalo y pulsa «Formatear y validar». Si es válido, verás el mensaje «JSON válido» con el texto formateado; si no, verás la línea, la columna y la explicación del error.
