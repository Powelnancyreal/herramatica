Este generador crea contraseñas verdaderamente aleatorias usando la API criptográfica del navegador (Web Crypto API), la misma tecnología que usan los gestores de contraseñas profesionales, no un simple Math.random() como hacen muchos generadores online. Ajusta la longitud y los tipos de caracteres, revisa el medidor de fortaleza basado en bits de entropía, y copia tu contraseña con un clic.

Cómo usar

  1. 1

    Ajusta la longitud de la contraseña con el control deslizante (de 4 a 64 caracteres)

  2. 2

    Elige qué tipos de caracteres incluir: mayúsculas, minúsculas, números y símbolos

  3. 3

    Activa "Excluir caracteres ambiguos" si necesitas evitar confusiones entre l, 1, I, O y 0

  4. 4

    Copia la contraseña generada, o pulsa el icono 🔄 para generar una nueva al instante

¿Por qué importa que la generación sea "criptográficamente segura"?

La función Math.random() de JavaScript, que usan muchos generadores de contraseñas online, no está diseñada para ser impredecible: es un generador pseudoaleatorio pensado para animaciones o juegos, no para seguridad. La Web Crypto API (crypto.getRandomValues), en cambio, usa el generador de números aleatorios del sistema operativo, diseñado específicamente para que sus resultados sean computacionalmente imposibles de predecir, el mismo estándar que usan los navegadores para generar claves criptográficas.

¿Qué es la entropía de una contraseña y por qué importa?

La entropía mide, en bits, cuántos intentos necesitaría un atacante para adivinar tu contraseña por fuerza bruta. Se calcula como longitud × log₂(tamaño del conjunto de caracteres). Una contraseña de 12 caracteres usando solo minúsculas tiene unos 56 bits de entropía, mientras que una de 12 caracteres con mayúsculas, minúsculas, números y símbolos supera los 78 bits, miles de millones de veces más difícil de adivinar. Como referencia general, se considera razonable a partir de 60 bits y fuerte a partir de 80 bits.

No. Toda la generación ocurre en tu navegador mediante JavaScript. Ninguna contraseña generada se envía, se registra ni se almacena en ningún servidor; el historial de contraseñas recientes desaparece si recargas la página.
