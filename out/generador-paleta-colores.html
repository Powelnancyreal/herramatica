Generador de Paletas de Colores

Actualizado el 25 de octubre de 2026 · Ver fuentes

Crea paletas de colores a partir de un color base o al azar: complementaria, análoga, triádica, complementaria dividida, tetrádica o monocromática. Bloquea los colores que te gusten y copia los códigos HEX o las variables CSS listas para pegar.

¿Cómo llevar la paleta a tu proyecto?

Copia los códigos HEX o las variables CSS y pégalos en tu hoja de estilos o en tu programa de diseño. Para afinar un tono usa el selector de color, para convertir entre formatos el conversor HEX a RGB, y cuando tengas la paleta, crea el ícono de tu sitio con el generador de favicon.

Preguntas frecuentes

Parte de un color que te guste y aplica una armonía: las análogas son seguras y tranquilas; las complementarias, llamativas. Después ajusta la luminosidad para tener colores claros y oscuros.

Selector de Color HEX, RGB y HSL

Elige un color y obtén su código HEX, RGB, HSL, HSV y CMYK. Mide el contraste WCAG con texto blanco y negro, genera tonos y toma colores de la pantalla.
