Conversor de CSV a JSON (y JSON a CSV)

3 registros · 4 columnas · delimitador «,». La conversión se hace en tu navegador.

Exportaste datos de Excel o de una base de datos en CSV y los necesitas en JSON para una API, o al revés. Este conversor transforma CSV a JSON y JSON a CSV al instante. Detecta automáticamente si el separador es coma, punto y coma, tabulador o barra vertical, y respeta las comillas y los saltos de línea dentro de los campos, como indica el estándar RFC 4180. Todo se procesa en tu navegador, así que puedes convertir datos privados sin subirlos a ningún sitio.

Cómo usar

  1. 1

    Elige la dirección: CSV → JSON o JSON → CSV

  2. 2

    Pega tus datos o abre un archivo .csv o .json desde tu equipo

  3. 3

    Ajusta las opciones: delimitador, primera fila como encabezados, detección de tipos y JSON compacto

  4. 4

    Copia el resultado o descárgalo como archivo

Beneficios

  • Conversión en ambos sentidos
  • Detección automática de coma, punto y coma, tabulador o barra
  • Maneja campos entre comillas con comas y saltos de línea
  • Convierte números y booleanos a su tipo JSON
  • Descarga el CSV con BOM para que Excel respete los acentos
  • Procesamiento local, sin límites de uso

Cómo se convierte un CSV en JSON

Cada fila del CSV se transforma en un objeto JSON cuyas claves son los nombres de columna de la primera fila. Así, la fila «Ana Pérez,31,Guadalajara» con los encabezados «nombre,edad,ciudad» se convierte en {"nombre": "Ana Pérez", "edad": 31, "ciudad": "Guadalajara"}. El resultado es un arreglo de objetos, el formato que esperan la mayoría de las APIs y librerías de JavaScript. Si desactivas los encabezados, cada fila se convierte en un arreglo de valores.

Comas, punto y coma y Excel

En países que usan la coma como separador decimal, como España o varios de Latinoamérica, Excel exporta los CSV con punto y coma en lugar de coma. El conversor cuenta los separadores fuera de las comillas en las primeras líneas y elige el más probable, aunque siempre puedes fijarlo a mano. Al exportar a CSV, la herramienta añade una marca BOM al inicio del archivo para que Excel reconozca la codificación UTF-8 y muestre bien los acentos y la ñ.

Comillas y campos especiales

Según el estándar RFC 4180, un campo que contiene el separador, comillas o saltos de línea debe ir entre comillas dobles, y las comillas internas se escriben duplicadas. Por ejemplo, "López, Luis" es un solo campo aunque tenga una coma, y "Dice ""hola""" representa el texto Dice "hola". El conversor sigue estas reglas en ambos sentidos, algo que un simple «dividir por comas» no hace y que suele romper los datos.

Tipos de datos

El CSV no tiene tipos: todo es texto. Con la opción «Detectar números y booleanos», los valores que parecen números (31, -2.5, 1e3) se convierten en números JSON, y true, false y null en sus valores literales. Ten cuidado con los códigos que empiezan con cero, como códigos postales o teléfonos: el conversor los conserva como texto porque un número JSON no admite ceros a la izquierda.

Preguntas frecuentes

No. La conversión se hace completamente en tu navegador, así que puedes usarla con datos confidenciales.
