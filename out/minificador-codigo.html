Minificador de JavaScript, CSS y HTML

Cada kilobyte que tu sitio envía retrasa su carga, sobre todo en redes móviles. Minificar elimina todo lo que el navegador no necesita: espacios, saltos de línea y comentarios. En JavaScript, además, acorta los nombres de variables y simplifica expresiones. Esta herramienta minifica JavaScript con Terser, el mismo motor que usan herramientas como webpack, y CSS y HTML con reglas que respetan las cadenas y los bloques preformateados. Te muestra el tamaño antes y después y el porcentaje de ahorro.

Qué hace la minificación

Minificar es transformar el código en una versión equivalente pero más pequeña. En todos los lenguajes se eliminan comentarios, espacios y saltos de línea innecesarios. En JavaScript, Terser va más allá: renombra variables locales a una o dos letras, elimina código inalcanzable, combina declaraciones y reescribe expresiones en formas más cortas, sin cambiar el comportamiento. En proyectos reales, la minificación suele reducir el JavaScript entre un 30% y un 60%, y el ahorro se suma al de la compresión gzip o brotli del servidor.

Minificar CSS sin romper nada

El minificador de CSS elimina comentarios y espacios alrededor de llaves, dos puntos, punto y coma y comas, y quita el último punto y coma de cada bloque. No toca el contenido de las cadenas, como los nombres de fuentes entre comillas o el texto de content, ni los espacios dentro de calc(), donde son obligatorios alrededor de + y −. Los comentarios que empiezan con /*! se conservan porque suelen contener licencias.

Minificar HTML

En HTML se eliminan los comentarios y los espacios de indentación entre etiquetas, y se reducen los espacios repetidos a uno solo. El contenido de pre, textarea y script se deja intacto, porque ahí los espacios importan, y los bloques style se minifican con el minificador de CSS. Como en HTML un espacio entre dos elementos en línea puede ser visible, la herramienta conserva un espacio donde había texto y solo elimina la indentación entre etiquetas en líneas distintas.

Buenas prácticas

Guarda siempre el código original: el minificado es difícil de leer y depurar. En proyectos con un proceso de compilación, como Next.js, Vite o webpack, la minificación ya se hace automáticamente en producción; esta herramienta es ideal para fragmentos sueltos, scripts de un sitio estático, plantillas de correo o para comparar resultados. Si necesitas depurar código minificado en producción, genera mapas de código fuente (source maps).

Preguntas frecuentes

No debería. Terser solo aplica transformaciones seguras. Si tu código depende de nombres de funciones en tiempo de ejecución, desactiva la opción de acortar nombres.
