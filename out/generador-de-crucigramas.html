¿Cómo escribir buenas pistas para un crucigrama?

Una sola respuesta posible

«Animal doméstico» admite muchas; «Animal doméstico que maúlla» solo una.

Adapta la dificultad

Para niños, definiciones directas; para adultos, sinónimos o juegos de palabras.

Varía el tipo de pista

Mezcla definiciones, frases para completar («Más vale ___ que nunca») y preguntas.

Revisa la ortografía

Una tilde de más o de menos no cambia la casilla, pero sí puede confundir al que resuelve.

¿Qué otros pasatiempos puedo crear para clase?

Con la misma lista de palabras puedes hacer una sopa de letras, más fácil para los pequeños. Para actividades de matemáticas tienes las tablas de multiplicar y el juego de cálculo mental.

Preguntas frecuentes
